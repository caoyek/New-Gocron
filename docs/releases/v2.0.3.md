# New-Gocron v2.0.3

## 更新内容

- 企业微信推送支持配置多个群机器人和多个通知模板，任务可分别选择对应的推送目标与模板。
- 定时任务页面新增移动端布局，手机访问时可使用搜索、筛选、置顶、状态切换、编辑、执行、日志和删除功能。
- 新增 Linux 一键安装与升级脚本，支持安装指定版本、自定义目录、自动备份以及任务节点运行用户切换。
- 完善任务节点端口访问限制、root 运行风险和升级操作说明。

## 升级说明

本次更新不涉及数据库结构变更。停止旧版服务后替换 `gocron` 主程序即可；任务节点功能未发生协议变更，旧节点可以继续使用，如需同步版本信息可同时替换 `gocron-node`。请保留原有的 `conf/app.ini`、`conf/install.lock` 和 `conf/.version`。
