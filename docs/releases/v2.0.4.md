# New-Gocron v2.0.4

## 更新内容

- 修复执行日志中任务节点名称的存储型 XSS：节点信息改为纯文本显示，新日志不再拼接 HTML，兼容已有日志。
- 优化任务通知选择区域：通知类型保持宽度，企微群和模板置于右侧；群标签在框内横向滚动，避免内容溢出。
- 修复浏览器窗口较小时任务编辑内容被裁切、无法滚动的问题，表单主体可滚动，标题及取消、保存按钮保持固定。

## 升级说明

本次更新不涉及数据库结构变更。停止旧版 Web 服务后替换 `gocron` 主程序即可，保留 `conf/app.ini`、`conf/install.lock` 和 `conf/.version`。

任务节点执行逻辑及通信协议未变，旧节点可继续使用；发行包中的节点程序仅同步版本号。本次未新增自动 TLS 或单任务日志保留功能。
