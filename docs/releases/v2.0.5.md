# New-Gocron v2.0.5

## 更新内容

- HTTP 任务支持 Params、JSON Body 和自定义 Headers，切换到 HTTP 默认 POST；JSON 留空不发送 Body，旧任务表单提交保持兼容。
- 新增任务到期自动暂停、单任务日志开关及 7天、30天、90天、180天、1年、永久保留选项；自动分批清理过期的已结束日志。
- 任务列表、执行日志新增显示字段选择，设置按当前浏览器和用户保存。
- 优化通知类型下拉选择及任务编辑布局。
- 修复旧 MySQL 通知接收字段类型引起的企微群选择丢失；加强 Header 校验和日志清理配置变更保护。

## 升级说明

升级前请备份数据库。停止 Web 服务并替换主程序，保留原有 `conf/app.ini`、`conf/install.lock` 和 `conf/.version`。

本版本在任务表新增 `http_headers`、`http_body_mode`、`http_body`、`expires_at`、`log_disabled`、`log_retention_days` 六个字段。启动时自动检查并补齐，不依赖版本文件变化；数据库账号需具备新增及修改字段权限，也可先执行 `gocron db-upgrade`。

旧任务默认不过期、开启日志并永久保留；新建任务默认保留日志 90 天。到期后禁止新执行，已经开始的任务及其重试允许结束。

任务节点通信协议与执行逻辑未变，旧节点可继续使用，无需同步升级。历史上已被整数列转换为 `0` 的企微群选择无法自动恢复，升级后需重新选择并保存。
